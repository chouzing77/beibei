# 背背 Android 1.0.0 试用版

安装包：`release/Beibei-1.0.0.apk`。Android 8.0 及以上；请保持 Android System WebView 为较新版本。此包使用独立发布签名，后续使用相同包名与签名可覆盖升级。

## 使用

把 APK 传到 Android 手机打开安装。应用内含网页全部静态资源，支持离线使用；无需账号。与网页使用同一套文件夹、卡片导入、图片答案、理解划线、积木画布、翻卡复习、统计、番茄钟及完整备份代码。

手机长按原文选中一段，调整范围后点“划出所选意群”；画布可缩放、全图显示。模板下载和备份导出使用系统“保存到”界面，导入和答案图片使用系统文件选择器。

电脑目录页“备份” → 导出完整备份 → 把 JSON 文件传到手机 → 手机“备份”选择文件并导入。返回电脑同理。合并时保留不同内容的副本，重复导入不会重复计算相同来源的统计；可以选择整库恢复。没有自动云同步。

资料保存在应用本机空间，卸载或清除数据前先导出备份。完整备份最多 100 MB，包含图片、积木和学习进度。备份本身未加密。

## 构建

运行 PowerShell 7：`./build.ps1`。

工具链（本地 `toolchain/`，不进入源码发布）：Microsoft OpenJDK 21、Android SDK platform 35、build-tools 35.0.0。应用使用 Android 自带 WebView 和系统文件选择器，不需要互联网权限或整盘存储权限。

构建从 `../../sites/beishu-lab/dist` 复制网页，使用 aapt2、javac、D8、zipalign、apksigner 生成安装包。安装包无原生 CPU 专用库，可用于不同 Android CPU 架构。

**维护者必须备份 `signing/` 目录中的发布密钥和密码，勿放入公开仓库或发给试用者。** 丢失签名后无法在保留安装身份的前提下继续覆盖升级。发布新版本须增加 AndroidManifest.xml 的 versionCode，并调整版本号与构建产物名称。
